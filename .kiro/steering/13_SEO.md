# 13 — SEO

1. یک `<h1>` در هر صفحه.
2. ساختار heading منطقی (h1 → h2 → h3).
3. `<title>` و meta description معنادار per-page.
4. HTML معنایی (`main`, `nav`, `article`, `header`, `footer`).
5. breadcrumb با structured data (schema.org) در آینده.
6. تصاویر `alt` توصیفی.
7. URL تمیز و معنادار (`/teachers/nazanin-hosseini`).
8. Open Graph و Twitter Card meta برای اشتراک‌گذاری.
9. `lang="fa"` و `dir="rtl"` روی html.
10. Canonical URL برای جلوگیری از محتوای تکراری.
11. Sitemap و robots.txt.
12. سرعت بارگذاری (Core Web Vitals) اولویت SEO.
